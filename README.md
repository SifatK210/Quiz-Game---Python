# 🧠 Python Quiz Game

An interactive command-line Quiz Game built with Python where players answer multiple-choice questions and get scored based on their performance.

---

## 📌 Features
- Multiple-choice quiz questions
- Score tracking system
- Instant answer checking
- Displays correct answers for wrong attempts
- Beginner-friendly Python project

---

## 🛠️ Technologies Used
- Python
- Functions
- Loops & Conditionals
- Lists & Dictionaries

---

## 🚀 How to Run

1. Clone this repository

```bash
git clone https://github.com/your-username/python-quiz-game.git
```

2. Open the project folder

```bash
cd python-quiz-game
```

3. Run the Python file

```bash
python main.py
```

---

## 🎮 How the Game Works
- The game displays quiz questions one by one.
- The player chooses an answer from the given options.
- The program checks whether the answer is correct.
- The final score and percentage are displayed at the end.
